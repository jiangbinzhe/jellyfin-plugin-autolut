# 发布流程

目标仓库：jiangbinzhe/jellyfin-plugin-autolut，公开。

1. 确认源码和 Release 包内容，不包含部署配置、SSH 文件、测试凭据、媒体、原始帧、运行日志或本机构建路径。
2. 检查 Git 的作者和提交者身份，使用 GitHub 用户名和 noreply 邮箱。
3. 运行编译、程序检查和隔离 Jellyfin 的仓库安装验证，记录支持范围与未验证项目。
4. 编译产物保存在忽略的 dist/ 目录，由 Release 分发，不提交到源码历史。
5. 推送 main 后可以检查 CI；推送与 csproj 版本匹配的 v* 标签会触发预发布 Release。
6. 发布后验证 ZIP、SHA256 和 manifest.json，确认清单地址指向对应版本资产。

首次公开发布须经仓库所有者确认。本次初始版本已经取得确认；后续版本按各自任务授权执行。

项目未指定开源许可证；第三方运行时许可证包含在包内。
