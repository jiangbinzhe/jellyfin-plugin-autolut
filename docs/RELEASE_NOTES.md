# 0.1.3 预发布版 — 网页开关与媒体库选择

用于安装与兼容性测试的预发布版，目标 NAS QSV 实播尚待验收。

- 同服务器网页播放器自动显示 LUT 开关，无需油猴脚本、不修改服务器网页文件。
- 切换仅作用于当前用户、浏览器设备及媒体，发送重播请求应用设置，保留进度、音轨、主字幕和队列。
- 管理页按名称勾选媒体库；匹配库内电影和剧集，兼容原有单媒体 ID 白名单。
- 用户白名单、播放权限及 SDR/1080p 限制保持有效，原生 App 仍无播放器开关。
- 暂停时可选择开关，保持暂停并在继续播放时应用；状态查询短暂失败时保留按钮。
- 同步播放、连接未就绪和部分复杂队列暂不支持切换；临时选择在服务器重启后清空。

详见 docs/WEB_CONTROLS.md。网页按钮表示调色请求，实际应用仍须确认服务端日志。
