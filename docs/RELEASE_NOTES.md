# 0.1.6 预发布版 — 未标记色彩与 4K SDR 兼容选项

本版新增两个独立、默认关闭的设置，保留已有 Mobile 网页开关修复：

- **兼容缺少色彩标记的 8-bit 视频（按 BT.709 处理）**：仅补足缺失的色域、传递函数或矩阵信息，不覆盖明确的非 BT.709 标记。抽帧分析和 LUT 转码使用相同的 BT.709 矩阵，原片及 Jellyfin 媒体元数据不改写。
- **允许最高 4K UHD 的 SDR 视频（3840×2160）**：允许 1440p 等中间尺寸；宽度超过 3840 或高度超过 2160 仍跳过，包括 4096×2160 DCI 和 8K。不会强制提高客户端输出分辨率。

两项均需管理员手动勾选并保存。白名单、字幕和转码图限制继续生效；HDR10/HLG、Dolby Vision、HDR10+、10-bit、隔行或旋转视频仍跳过。每个播放会话冻结色彩假设，改配置后需重新播放。

## 更新

固定插件仓库地址不变：

https://raw.githubusercontent.com/jiangbinzhe/jellyfin-plugin-autolut/main/manifest.json

安装 **0.1.6.0** 后重启 Jellyfin，刷新网页或完全退出并重新打开 App。在 Auto LUT 设置中按需要开启以上兼容选项、保存，再重新播放。无需修改原始视频文件。

自动模式仍可能因没有可用肤色而跳过。按钮“开”代表允许调色，不代表 FFmpeg 已应用；缺失色彩模式实际应用日志包含 `cpu-lut-qsv-assumed-bt709`。

## 验证与限制

Release 编译无警告、无错误；163 项程序断言、9 项网页脚本测试、4 项清单测试通过。包含真实 3840×2160 合成帧的 CPU LUT 处理、BT.709 像素参考比较、软件编码输出色彩标记、HDR/10-bit/超尺寸拒绝及会话冻结验证。

这些测试不等于 NAS 的 4K 实时性能验收。仍使用 CPU LUT + QSV 编码，4K 输出可能增加负载；需要在目标机器实播验证，必要时降低客户端输出分辨率或关闭 4K 选项。此版不修复 Swiftfin 默认 VLC 播放器黑屏，也不增加原生播放器内的按钮。
