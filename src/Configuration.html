Auto LUT · 0.1.7 预发布版

仅 Jellyfin 12.1 / Linux x64。8-bit SDR，默认 BT.709，可选隔行／SMPTE 170M 兼容；默认最高 1080p，可选放宽到 4K UHD。CPU LUT + QSV 编码。每次播放固定一个 LUT。

默认关闭。隔行视频复用 Jellyfin 核显去隔行；三项色彩标记均为 SMPTE 170M 时，先在 CPU 转换为 BT.709 再应用 LUT。可能增加负载；不改原文件，保存后重新播放。

默认关闭。开启后放宽输入视频尺寸限制，超过 3840×2160 仍跳过；不会强制提升输出分辨率。4K LUT 可能增加 CPU 负载，出现卡顿可关闭此项并重新播放。HDR、Dolby Vision 和 10-bit 仍不处理。

默认关闭。仅补足缺失的色彩标记，不覆盖已知非 BT.709 信息；HDR、Dolby Vision 和 10-bit 仍会跳过。不修改原文件；若颜色异常可关闭此项并重新播放。

勾选后覆盖库内的电影和剧集。未选择媒体库时，可用下方单个媒体 ID 测试。用户白名单始终有效。

无可用肤色、HDR、10-bit、多版本媒体及烧录字幕等会跳过。支持由客户端单独显示的普通文本字幕。自动分析尚不含人脸检测。最多保留 8 个未结束会话；收到播放结束通知后释放额度。未正常结束的会话会占用额度，重启后恢复。
